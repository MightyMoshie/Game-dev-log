# Log — Red Day v0

**Date:** 2026-08-28  
**Decision:** Red Day is the first playable inside this studio home, as a self-contained project under `red-day/`. The rest of the repo (this log, the studio README, CI) stays. We did not flatten the studio into a single-game dump.

## Why a browser smoke, not TikTok-first

The v0 goal is to feel the loop on a phone-width web page in under 45 seconds: brief → floor → roast → desk → next brief. No TikTok Mini Game SDK, no login, no real ads. If the satire and the two-button desk fantasy work here, we port the same loop to Cocos later.

## What v0 is allowed to be

- Seeded fake tape (`CHAI` / `NBL` / `BLND` only).
- Maya on the book. Player: Let them ride / Yank.
- Roast card as the shareable punchline.
- Accountant unlock after the first real red day (size cap, idle drip, fewer blowups).
- Local save.

## What v0 is not

Real stocks, tutorials-as-quizzes, a roster maze, monetization, or a Bloomberg cosplay. Teaching is the bruise from babysitting, not a pop quiz.

## Follow-ups

- Cocos / TikTok Mini Game port of this same loop.
- Optional real ad hook behind the existing “Watch to replay the day” placeholder.
- More trainees only after Maya + Accountant read clearly.
